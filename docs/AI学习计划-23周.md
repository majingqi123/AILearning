## 1. 计划说明

### 1.1 目标

按“AI 辅助编程 → AI 应用开发 → AI 融入 3D 引擎”的方向求职。本计划负责前两步和理论、前沿部分，学完后应当能做到：

- 熟练用 AI 编码工具完成日常 C++ 开发，并有一套自己的工作流。
- 讲清楚神经网络、Transformer、LLM 训练与推理的原理，亲手训练过一个小 GPT。
- 独立开发 RAG、Agent、MCP Server，并把它们封装成可用的服务。
- 能在本机部署、量化、微调开源模型，会从 C++ 调用推理库。
- 对多模态、扩散模型、AI + 3D、世界模型等前沿方向有清晰的知识地图。
- 有一个能写进简历的综合项目：知识库 + 代码生成 Agent。

### 1.2 范围

- **不含自研 3D 引擎的开发任务**，引擎另行计划。引擎与 AI 的集成放在本计划完成之后，第 12 节说明如何衔接。
- 向量、矩阵等图形学里已经掌握的数学不再单独安排。
- 不做 Pandas 数据分析专题，也不做依赖公司环境的 AI Code Review 项目。

### 1.3 时间

- 主体 23 周，约 200 小时；另留最多 3 周缓冲，总周期 5.5-6 个月。
- 如果从 2026-11-30（周一）开始，主体在 2027-05-09 结束，用满缓冲则到 2027-05-30。
- 2027 年春节在 2 月上旬，大约落在 W10-W11，可以提前安排一周缓冲。

## 3. 环境准备

### 3.1 硬件要求一览

计划不绑定某台电脑。大部分周只需要一台能跑 Python 和 C++ 编译器的电脑；下表这几周有额外要求，对应周的开头也标了“硬件要求”。表里的显存数字是估计值，学到那一周时按当时的电脑再确认。

| 周次 | 内容 | 硬件要求 | 达不到时的做法 |
|---|---|---|---|
| W6 | 在 MNIST 上训练 MLP 和 CNN | 有 NVIDIA 显卡更快，不是必需 | 用 CPU 训练，只是慢一些 |
| W8-W9 | 训练小 GPT | 建议 NVIDIA 显卡，显存 4GB 以上 | 缩小模型在 CPU 上训练，或用云端 GPU |
| W10 | 加载开源模型、QLoRA 微调 | 需要 NVIDIA 显卡；0.5B-1.5B 的模型建议显存 6GB 以上，模型越大要求越高 | 用云端 GPU |
| W11 | Ollama、llama.cpp、ONNX Runtime | CPU 就能跑；4-bit 量化的 7B 模型大约需要 6GB 显存或 8GB 以上空闲内存；GPU 加速需要 NVIDIA 显卡 | 换更小的模型 |
| W13-W14 | 本地 Embedding 模型和重排模型 | CPU 就能跑，有显卡更快 | 改用 Embedding API |
| W19 | 扩散模型、视觉语言模型、语音识别 | 扩散模型建议显存 6GB 以上，较新的大模型需要 8-12GB 甚至更多；Whisper 的小模型 CPU 能跑 | 用小模型、降分辨率，或用在线服务 |
| W20 | 3D Gaussian Splatting | 查看预训练场景：支持 OpenGL 4.5 的显卡，建议显存 4GB；训练：NVIDIA 显卡，官方实现要达到论文质量需 24GB 显存，小场景降分辨率可以低很多 | 只做查看，不做训练 |

其余周没有特殊硬件要求。W12 起需要云端模型 API，见 3.4 节。

### 3.2 PyTorch

W3 安装，按当时的电脑选版本。

**有 NVIDIA 显卡**：先用 `nvidia-smi` 看驱动支持的 CUDA 版本，再从对应的源安装。下面以 CUDA 12.6 为例：

```powershell
python -m pip install torch torchvision --index-url https://download.pytorch.org/whl/cu126
python -c "import torch; print(torch.__version__, torch.cuda.is_available())"
```

第二条命令应输出 `True`。输出 `False` 说明装成了 CPU 版，卸载后带上 `--index-url` 重装。

**没有 NVIDIA 显卡**：按 [PyTorch 官网](https://pytorch.org/get-started/locally/) 的选择器装 CPU 版，W3-W7 都够用。

参考记录：2026-11-24 在当前电脑上（RTX 3050 6GB，驱动 560.94，Python 3.14）查过，`cu126` 源有 torch 2.14.1 和 torchvision 0.29.1 可装。换电脑后以新电脑为准。

## 12. 完成之后：与自研引擎的衔接

综合项目换一个对象就是你最初的设想：把图形库换成自研引擎，知识库换成引擎的文档和示例。为了让这一步顺利，做引擎时可以提前留意四点：

- **对外接口要高层、稳定**：AI 生成的代码越短，出错越少。
- **每个功能配一个最小示例**：示例是知识库里最有用的材料。
- **公共头文件写规范注释**：方便自动提取成 API 文档。
- **支持无窗口运行和截图**：Agent 才能自己验证结果。
