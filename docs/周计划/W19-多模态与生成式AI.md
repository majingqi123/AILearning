# W19 周计划：多模态与生成式 AI

- **所属阶段**：阶段六 前沿技术（W19-W21）
- **起止日期**：
- **计划用时**：工作日 5 × 约 1.5 小时 + 周末约 3 小时，共约 10–11 小时
- **硬件要求**：CLIP / Whisper 小模型 CPU 可跑。扩散模型建议 NVIDIA、显存 6GB+；不够就降分辨率、换小模型或用在线服务。本地 VLM 也要显卡，可改用 API
- **主计划**：[AI 学习计划（23 周）](../AI学习计划-23周.md)
- **上一周**：[W18](W18-工程化评测与安全.md)

## 1. 本周目标

学完这一周，你应该能做到：

1. 讲清 ViT / CLIP 的基本思路，并完成一次图文检索。
2. 理解视觉语言模型的常见结构，用 API 或小模型做图片问答（含 3D 场景截图）。
3. 用 Whisper 跑通语音转文字，知道 ASR/TTS 的基本分工。
4. 讲清扩散模型前向加噪与反向去噪的直觉，以及 Latent Diffusion / DiT / Flow Matching 的定位。
5. 每个主题按统一模板写一页笔记：是什么、解决什么问题、核心原理、和 3D 引擎有什么关系。

## 4. 每日安排

### 周一：ViT 与 CLIP 图文检索

**学习目标**

1. 理解 ViT：图像切块当 Token。
2. 理解 CLIP：图文对比学习对齐空间。
3. 做一次图搜文或文搜图。

**时间安排**：读资料 35 分钟，动手 40 分钟，笔记 15 分钟。

**学习资源**

| 资料 | 语言 | 要求 | 看什么 |
|---|---|---|---|
| [CLIP 仓库](https://github.com/openai/CLIP) | 英文 | 必读 | README 与用法 |
| [动手学深度学习：注意力/ViT 相关（若有）](https://zh.d2l.ai/) | 中文 | 选读 | Vision Transformer 直觉 |
| CLIP 论文摘要 | 英文 | 选读 | 对比学习目标 |

**动手任务**

1. 用 CLIP 编码 10–20 张图与若干文本查询。
2. 实现文搜图：输入“红色的车”等，看 Top-K 是否合理。
3. 写四问笔记，重点写：引擎里能否用 CLIP 做素材检索/截图检索。

**验收标准**

- [ ] 图文检索可运行并有样例结果。
- [ ] 四问笔记完成。

**自测题**

1. CLIP 训练时为什么需要大量图文对？
2. ViT 的 patch 大小如何影响精度与算力？
3. CLIP 相似度高是否等于“图中真有该物体”？

---

### 周二：视觉语言模型（VLM）图片问答

**学习目标**

1. 知道常见 VLM 结构：视觉编码器 + 投影/对齐 + LLM。
2. 完成图片问答；试一张 3D 场景截图。

**时间安排**：读资料 25 分钟，实验 50 分钟，笔记 15 分钟。

**学习资源**

| 资料 | 语言 | 要求 | 看什么 |
|---|---|---|---|
| 任一开源 VLM 模型卡或 API 文档（LLaVA / Qwen-VL 等） | 中/英 | 必读 | 输入里如何塞图像 |
| Happy-LLM 或多模态综述章节（若有） | 中文 | 选读 | 结构示意 |

**动手任务**

1. 用 API 或本地小 VLM：对普通照片问 3 个问题。
2. 对 3D 场景截图问：物体、布局、可能的引擎后处理（bloom/阴影）等。
3. 记录失败：幻觉出不存在的物体、数不清数量、不懂游戏 UI。
4. 四问笔记：和实时引擎结合可能落在测试、截图验收、关卡理解哪些点。

**验收标准**

- [ ] 有实验记录（含 3D 截图）。
- [ ] 四问笔记完成。

**自测题**

1. 为什么很多 VLM 不直接把像素喂给 LLM？
2. 高分辨率截图通常如何处理？
3. 用 VLM 做 Agent 验收（看截图）时最大风险是什么？

### 周三：音频 AI——Whisper

**学习目标**

1. 区分 ASR 与 TTS。
2. 用 Whisper 完成一次语音转文字。

**时间安排**：读资料 20 分钟，动手 50 分钟，笔记 20 分钟。

**学习资源**

| 资料 | 语言 | 要求 | 看什么 |
|---|---|---|---|
| [Whisper 仓库](https://github.com/openai/whisper) | 英文 | 必读 | 模型体量与用法 |
| ASR/TTS 概念短文任意可信来源 | 中/英 | 必读 | 管线位置 |

**动手任务**

1. 录一段 30–60 秒中文/英文（或用现成音频）。
2. 用 Whisper 小模型转写；对比不同模型尺寸的速度与错字。
3. 四问笔记：游戏/引擎场景里语音指令、配音流水线可能怎么用。

**验收标准**

- [ ] 有转写文本与简短对比。
- [ ] 四问笔记完成。

**自测题**

1. 为什么小模型在嘈杂环境更容易翻车？
2. ASR 输出如何接到 LLM Agent？
3. TTS 和 ASR 哪边更常需要风格控制？

### 周四：扩散模型基础（DDPM / DDIM）

**学习目标**

1. 建立前向加噪、反向去噪的直觉。
2. 知道 DDPM 与 DDIM 的定位差异。

**时间安排**：读资料 55 分钟，笔记 25 分钟，自测 10 分钟。

**学习资源**

| 资料 | 语言 | 要求 | 看什么 |
|---|---|---|---|
| [Diffusers 文档：理论/介绍](https://huggingface.co/docs/diffusers) | 英文 | 必读 | Pipeline 与概念页 |
| DDPM 论文摘要 | 英文 | 选读 | 前向/反向过程 |
| 中文扩散模型通俗讲解（可选，注意质量） | 中文 | 选读 | 建立直觉 |

**动手任务**

1. 手绘一张：清晰图 → 逐步加噪 → 噪声；再反向箭头标注“网络预测什么”。
2. 笔记对比 DDPM vs DDIM：采样步数与质量的大致关系。
3. 四问笔记先写“原理版”，周五补现代变体。

**验收标准**

- [ ] 能不看资料讲清加噪/去噪在干什么。
- [ ] 原理笔记完成。

**自测题**

1. 扩散模型训练时网络常见预测目标是什么（噪声/速度等）？
2. 为什么采样步数减少可能变差？
3. 条件生成（文本条件）大概加在哪里？

---

### 周五：Latent Diffusion、DiT、Flow Matching 与现状

**学习目标**

1. 理解为什么在潜空间扩散（VAE + U-Net/DiT）。
2. 知道 DiT、Flow Matching 在生成模型谱系中的位置。
3. 对图像/视频生成现状有一句自己的判断。

**时间安排**：读资料 50 分钟，笔记 30 分钟，自测 10 分钟。

**学习资源**

| 资料 | 语言 | 要求 | 看什么 |
|---|---|---|---|
| Stable Diffusion / Latent Diffusion 介绍（Diffusers 或论文摘要） | 英文 | 必读 | VAE、U-Net、文本条件 |
| DiT 论文摘要 | 英文 | 选读 | Transformer 作骨干 |
| Flow Matching 综述/博客摘要 | 英文 | 选读 | 与分数匹配的直觉差别 |
| Hugging Face Papers 扫一眼生成向热门 | 英文 | 选读 | 现状语感 |

**动手任务**

1. 画 Latent Diffusion 框图：像素 ↔ 潜空间 ↔ 去噪网络 ↔ 文本条件。
2. 表格：U-Net 扩散 / DiT / Flow Matching——你只记“各解决什么痛点”。
3. 四问笔记补全“和引擎关系”：概念图、材质、天空盒、原型立绘等（务实写，不神化）。

**验收标准**

- [ ] 框图与对比表完成。
- [ ] 现状判断有依据（哪怕简短）。

**自测题**

1. 潜空间扩散主要省了什么？
2. 视频生成相对图片多了什么难题？
3. 为什么引擎里“实时扩散”仍然困难？

**时间安排**（约 3 小时）：环境与出图 100 分钟，整理 40 分钟，复盘 20 分钟。

**学习资源**

| 资料 | 语言 | 要求 | 看什么 |

**动手任务**
