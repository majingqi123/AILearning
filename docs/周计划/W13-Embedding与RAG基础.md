## 1. 本周目标

学完这一周，你应该能做到：

1. 用本地 Embedding 模型把句子变成向量，做余弦相似度检索。
2. 建 FAISS 索引，并知道 Flat / IVF / HNSW 以及常见向量库的定位。
3. 会做文档切分（大小、重叠、按 Markdown 标题）并保留元数据。
4. 搭出最简 RAG：检索 Top-K → 拼提示词 → 生成 → 标注来源。
5. 用自己的学习笔记做知识库，能分析答错是切分、检索还是生成的问题。

## 4. 每日安排

### 周一：Embedding、余弦相似度、语义搜索

**学习目标**

1. 理解 Embedding 把文本映射到向量空间。
2. 会算余弦相似度，并做小规模语义搜索。

**时间安排**：读资料 30 分钟，动手 45 分钟，笔记 15 分钟。

**学习资源**

| 资料 | 语言 | 要求 | 看什么 |
|---|---|---|---|
| [Sentence Transformers 文档](https://www.sbert.net/) | 英文 | 必读 | 快速开始、语义搜索 |
| [Hugging Face：语义搜索概念](https://huggingface.co/learn/nlp-course/chapter5/6) | 英文 | 选读 | FAISS 前置直觉 |
| [BGE / 中文 Embedding 模型卡](https://huggingface.co/BAAI) | 中/英 | 必读 | 选模型与用法说明 |

**动手任务**

1. 加载 Embedding 模型，编码 20–50 句中文（含近义、反义、无关）。
2. 计算相似度矩阵，检查近义句是否更高。
3. 实现：给定 query，返回 Top-5 句子及分数。
4. 记录向量维度、编码速度、是否需要 `normalize_embeddings`。

**和已有知识的联系**：这和 W7 的词向量同族，但是句级；检索时常用归一化后的点积代替显式余弦。

**验收标准**

- [ ] Top-K 检索脚本可运行。
- [ ] 能解释为何“关键词不同但意思接近”仍可能被找到。

**自测题**

1. 余弦相似度和欧氏距离在归一化向量上是什么关系？
2. 短 query 对长文档直接整篇 Embedding 有什么问题？
3. 指令式 Embedding 模型（带 query 指令）要注意什么？

**学习目标**

2. 会按 Markdown 标题做结构感知切分。
3. 为每个 chunk 保存来源路径、标题路径、起止位置等元数据。

**时间安排**：读资料 20 分钟，动手 55 分钟，笔记 15 分钟。

**学习资源**

| 资料 | 语言 | 要求 | 看什么 |

## 7. 容易踩的坑

- **整篇文档当一个向量**：长文检索会很糊，必须切分。
- **只看生成答案不看命中 chunk**：无法定位故障。
- **中英文模型混用**：中文笔记配英文-only Embedding 会掉很多。
- **提示词允许“发挥”**：知识库问答要显式禁止脱离资料编造。
- **索引与原文不同步**：改了笔记忘了重建索引。
