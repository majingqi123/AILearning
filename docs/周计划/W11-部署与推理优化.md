## 1. 本周目标

学完这一周，你应该能做到：

1. 讲清常见精度与量化路线，会估算 7B 模型权重大小。
2. 用 Ollama 跑量化模型，并调用 OpenAI 兼容接口。
3. 编译 llama.cpp，写一个最小 C++ 对话程序。
4. 把 W6 的 CNN 导出 ONNX，并用 ONNX Runtime C++ 推理。
5. 说明量化、LoRA、KV Cache、批处理优化各自解决什么问题（阶段四检查点）。

## 4. 每日安排

### 周一：量化与模型体积

**学习目标**

1. 分清 FP32 / FP16 / BF16 / INT8 / INT4。
2. 知道 PTQ、QAT、GPTQ、AWQ、GGUF 的定位差异。
3. 会估算权重大小。

**时间安排**：读资料 45 分钟，估算与笔记 30 分钟，自测 15 分钟。

**学习资源**

| 资料 | 语言 | 要求 | 看什么 |
|---|---|---|---|
| [llama.cpp README（量化相关说明）](https://github.com/ggml-org/llama.cpp) | 英文 | 必读 | GGUF、常见量化类型 |
| [Hugging Face：量化概述](https://huggingface.co/docs/transformers/quantization) | 英文 | 必读 | 概念与常见方法入口 |
| [GPTQ 论文](https://arxiv.org/abs/2210.17323) | 英文 | 选读 | 摘要 |
| [AWQ 论文](https://arxiv.org/abs/2306.00978) | 英文 | 选读 | 摘要 |

**动手任务**

1. 估算 7B 参数模型在 FP32 / FP16 / INT8 / INT4 下的权重字节数（写清公式：`params × bytes_per_param`）。
2. 做对比表：PTQ vs QAT；GPTQ vs AWQ vs llama.cpp 量化——各适合什么场景（一句话即可）。
3. 记录：推理时除了权重，还要为 KV Cache、激活预留什么。

**验收标准**

- [ ] 体积估算正确（数量级对）。
- [ ] 能解释为什么“能加载权重”不等于“能顺畅生成长文本”。

**自测题**

1. BF16 相比 FP16 的主要工程好处是什么？
2. GGUF 主要服务哪类运行时？
3. 量化最常见的质量风险是什么？

### 周五：CNN → ONNX → ONNX Runtime C++

**学习目标**

1. 把 W6 CNN（或替代小模型）导出为 ONNX。
2. 用 ONNX Runtime C++ API 跑通一次推理。
3. 知道 TensorRT 在工具链中的位置。

**时间安排**：导出 30 分钟，C++ 推理 50 分钟，笔记 20 分钟。

**学习资源**

| 资料 | 语言 | 要求 | 看什么 |
|---|---|---|---|
| [PyTorch ONNX 导出](https://docs.pytorch.org/docs/stable/onnx.html) | 英文 | 必读 | `torch.onnx.export` |
| [ONNX Runtime 文档](https://onnxruntime.ai/docs/) | 英文 | 必读 | C++ 快速开始 |
| [TensorRT 产品页/文档入口](https://developer.nvidia.com/tensorrt) | 英文 | 选读 | 定位：NVIDIA 上的推理优化器 |

**动手任务**

1. 导出 ONNX，用 Python `onnxruntime` 先验证数值与 PyTorch 一致（或大致一致）。
2. 写 C++ 程序：加载 ONNX、准备输入张量、跑 session、打印类别或分数。
3. 笔记里写清：ONNX 是交换格式；ORT 是通用运行时；TensorRT 是 NVIDIA 上进一步吃性能的编译器/引擎。

**验收标准**

- [ ] Python 与 C++ 都能对同一 ONNX 推理。
- [ ] `onnx-infer` 目录有 README 与复现步骤。

**自测题**

1. 为什么游戏/引擎岗常更关心 ONNX Runtime / TensorRT，而不是只停在 PyTorch？
2. 动态 batch / 动态尺寸导出时要注意什么？
3. 导出失败最常见原因有哪些（动态控制流、不支持算子等）？

## 7. 容易踩的坑

- **编译劝退**：周三卡住就换 CPU 版选项，先跑通再开 CUDA。
- **模型过大导致交换内存**：表现是“能加载但生成极慢”，换小 GGUF。
- **把 CLI 当作业交差**：周四必须有自己的 C++ 入口文件。
- **ONNX 只导出不验证**：先 Python ORT 数值对一下，再写 C++。
- **周末钻进 CUDA 细节**：本周要的是地图，不是成为 CUDA 工程师。
