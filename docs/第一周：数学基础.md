## 2.4 重点知识

### 向量点积

两个向量的点积：

a · b = |a| × |b| × cosθ

其中：

- |a|：向量 a 的长度。
- |b|：向量 b 的长度。
- θ：两个向量之间的夹角。

点积可以反映两个向量方向上的相似程度。

### 余弦相似度

cosθ = (a · b) / (|a| × |b|)

在 AI 中的应用：

- 一段文字可以通过 Embedding 模型转换为一个向量。
- 两段文字可以转换为两个向量。
- 通过计算两个向量的余弦相似度，可以衡量它们在向量空间中的接近程度。

这是后续学习 RAG、向量数据库、语义搜索的重要基础。

## 3.4 重点知识

### 矩阵乘法

矩阵乘法并不是简单地将两个矩阵对应位置的元素相乘。

矩阵乘法需要满足：

第一个矩阵的列数 = 第二个矩阵的行数。

例如：

A 是 2×3 矩阵，B 是 3×2 矩阵。

那么：

AB 的结果是 2×2 矩阵。

### 线性变换

矩阵可以表示空间中的线性变换。

例如二维旋转：

R(θ) =

[ cosθ  -sinθ ]

[ sinθ   cosθ ]

通过矩阵与向量相乘，可以实现二维空间中的旋转。

这与你熟悉的 OpenGL、3D 渲染中的变换矩阵有直接联系。

## 4.4 重点知识

### 导数

导数描述单变量函数在某个位置的瞬时变化率。

例如：

f(x) = x²

那么：

f'(x) = 2x

当 x = 2 时：

f'(2) = 4

### 偏导数

对于多变量函数：

f(x, y) = x² + y²

分别对 x 和 y 求偏导：

∂f/∂x = 2x

∂f/∂y = 2y

### 梯度

梯度是多变量函数所有偏导数组成的向量。

对于上面的函数：

∇f = [2x, 2y]

梯度可以表示函数增长最快的方向。

而负梯度方向则是函数局部下降最快的方向。

后续学习神经网络反向传播时会频繁接触这个概念。

## 5.4 重点知识

### 条件概率

条件概率表示在某个条件已经成立的情况下，另一个事件发生的概率。

### 贝叶斯公式

P(A|B) = P(B|A) × P(A) / P(B)

它描述的是：

当我们获得新的证据后，如何更新对某件事情发生概率的判断。

这对后续理解机器学习中的概率推断、朴素贝叶斯分类器等有帮助。

### 均值、方差、标准差

- 均值：数据的平均水平。
- 方差：衡量数据相对于均值的离散程度。
- 标准差：方差的平方根，表示数据的典型波动范围。

### 正态分布

正态分布是一种常见的连续概率分布，其图形通常呈钟形。

重点理解：

- 均值决定分布中心。
- 标准差决定分布的离散程度。

## 6.4 重点知识

### 损失函数

损失函数用于衡量模型预测结果与真实结果之间的差异。

损失越小，通常说明模型预测结果越接近真实结果。

### 梯度下降

梯度下降是一种优化方法。

通过计算函数梯度，并沿负梯度方向更新参数，让损失逐渐降低。

更新公式：

x_new = x_old - η × f'(x_old)

其中：

- x_old：当前参数。
- η：学习率。
- f'(x_old)：当前梯度。

### 不同优化算法

| 算法     | 核心思想                       |
| -------- | ------------------------------ |
| SGD      | 使用随机采样得到的梯度更新参数 |
| Momentum | 引入动量，减少更新过程中的震荡 |
| Adam     | 结合动量和自适应学习率         |

重点理解：

模型训练的本质，就是不断调整模型参数，使损失函数尽可能降低。

## 6.5 Python 实践

目标函数：

f(x) = (x - 5)² + 3

导数：

f'(x) = 2(x - 5)

梯度下降更新公式：

x_new = x_old - η × f'(x_old)

实现：

```
def f(x):
    return (x - 5) ** 2 + 3

def gradient(x):
    return 2 * (x - 5)

x = 0
learning_rate = 0.1

for i in range(100):
    x = x - learning_rate * gradient(x)

    if i % 10 == 0:
        print(
            f"Iteration: {i}, "
            f"x: {x:.6f}, "
            f"loss: {f(x):.6f}"
        )

print("最终结果:", x)
```
